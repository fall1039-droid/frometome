# LiVOS Video Object Segmentation
This project implements and analyzes the paper:

"LiVOS: Light Video Object Segmentation with Gated Linear Matching" (CVPR 2025)

The objective is to understand memory-based video object segmentation and reproduce the official implementation using PyTorch.

## Features

- Video Object Segmentation
- Memory-based tracking
- Gated Linear Matching analysis
- PyTorch implementation
- Google Colab execution
- 
## How to Run

1. Open the Colab notebook
2. Run all cells
3. Segmentation results will be generated automatically

## Results

The model successfully tracks the initialized object across video frames using memory-based matching.
